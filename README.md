# Bandit Motion Studio

Bandit Motion Studio is an open-source, no-code motion playground for Bandit, a community-driven humanoid robot.

Create expressive gestures, animate joints, build movement sequences, and record robot behaviors through an interactive 3D environment—no robotics programming experience required.

## What Can You Do?

- **Create motions** — Control Bandit's joints and design custom poses and gestures.
- **Animate behaviors** — Build movement sequences using timelines, keyframes, and reusable motions.
- **Preview movements** — Explore robot motion with visual feedback and physical feasibility checks.
- **Record and share** — Save motions, replay animations, and share creations with the community.
- **Contribute to Bandit** — Submit movements for automated validation, review, and potential inclusion in Bandit's open-source motion library.

## How It Connects

**[Bandit Robotics](https://github.com/banditteam/bandit-robotics)** provides the robot's physical simulation, controllers, and motion policies.

**Bandit Motion Studio** provides the community-facing environment for creating, recording, and contributing new behaviors.

The Studio is designed to make robotic motion creation accessible while connecting community creativity with physically grounded robotics development.

## Development

The Motion Studio is under active development. The application structure, setup instructions, and contribution workflow will be documented as the existing implementation is integrated into this repository.
